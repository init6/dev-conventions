## 知識共有規約

複数人・複数端末・複数セッションで開発するため、**知識・経緯はできる限り Git（対象リポジトリ）に残す**。個人のメモではなく、誰でも参照できる形にする。

- 調査結果・設計判断・運用ルール・移植時の気づき・ハマりどころなどの知識は、`CLAUDE.md` / `README` / `docs/` などに **md としてコミット**し、チームで共有する。
- **Claude Code の memory 機能（`~/.claude/.../memory/`）には業務知識を保存しない。** memory は端末・人をまたいで同期されず、別端末や他メンバーの Claude から参照できないため、正本にしない。
- 「これは次回以降・別端末・他メンバーでも知っておくべき」と判断した知識は、上記の Git 管理 md に追記する。
